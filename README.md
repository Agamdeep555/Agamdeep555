## 🚀 Featured Projects

### 🧠 Quiz O Mania
An AI-powered quiz generator that creates 10 MCQs per PDF within 5–10 seconds, supporting documents up to 200MB.

🔹 **Tech Stack**: Python, Streamlit, LangChain, Groq, PyPDF2, python-docx  
🔹 **Key Features**: 
- Dynamic MCQ generation from diverse documents (lecture notes, medical reports, legal documents)
- LLM-based answer evaluation with detailed explanations
- Adaptive difficulty levels & seamless DOCX export

🔗 [Code](https://github.com/Agamdeep555/Quiz_o_mania) | [Live Demo](https://quizomania-agam.streamlit.app)

---

### 💼 AI Resume Analyzer
A full-stack application that processes resumes, extracts skills, and generates ATS scores (0–100) using AI.

🔹 **Tech Stack**: Node.js, Express.js, MongoDB, Cerebras, Vercel  
🔹 **Key Features**:
- Architected backend APIs for resume processing and skill extraction
- Integrated Cerebras LLM API for intelligent role-based evaluation
- Secure file handling with Multer, CORS, and MongoDB Atlas
- Production-ready deployment with CI/CD pipelines

🔗 [Code](https://github.com/Agamdeep555/AI_Resume_backend) | [Live Demo](https://ai-resume-frontend-snowy.vercel.app)

---

### 🌿 LeafGuard-CNN
An end-to-end deep learning pipeline for crop disease detection using transfer learning.

🔹 **Tech Stack**: TensorFlow, Keras, EfficientNetV2B3, Python  
🔹 **Key Features**:
- Built with **EfficientNetV2B3** backbone and ImageNet transfer learning
- CLAHE-based image preprocessing for enhanced feature representation
- Achieved **92.7% training accuracy** and **89.4% validation accuracy**
- Robust performance on unseen agricultural disease data

🔗 [Code](https://github.com/Agamdeep555/LeafGuard-CNN)
